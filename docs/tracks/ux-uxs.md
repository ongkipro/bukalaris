## Accessibility & interaction checks

1. **Zero horizontal page overflow (`320`, `390`, `1366`, `1536` CSS px):** Measured `document.documentElement.scrollWidth - document.documentElement.clientWidth === 0` across all 21 Seller Admin routes and all 4 viewports.
2. **Heading & landmark hierarchy:** Verified exactly one `<main id="main" tabIndex={-1}>` and one `<h1>` inside `<main>` on every route and state (empty, loaded, denied, read-only).
3. **Keyboard navigation & focus order:**
   - First `Tab` on a fresh load focuses the skip link (`Lewati ke konten utama`), `Enter` moves focus to `<main id="main">` (`ui.spec.ts`).
   - `Tab` from `Produk` in the `Seller` nav focuses `Inventaris`, `Enter` navigates and updates `aria-current="page"` (`ui.spec.ts`).
   - Period switcher on `/seller` (`Hari ini` → `7 hari` → `30 hari`) and channel selector + submit on `/seller/billing` operate by `Tab` + `Enter` (`dashboard.spec.ts`, `t50.spec.ts`).
   - New product creation form (`/seller/products/new`) completes end to end by keyboard only (`ui.spec.ts`).
4. **Form labels, `aria-describedby`, and `aria-invalid`:** Every `<Input>`, `<NativeSelect>`, and `<Textarea>` has an explicit `<Label htmlFor>` (or `sr-only` label in compact row forms); added missing `aria-describedby` links on `/seller/finance` (`accountHolderName` → `#holder-help`, `dest-code` → `#dest-help`, `payout-code` → `#amount-help`).
5. **Target size (`WCAG 2.2 SC 2.5.8`, `≥ 24×24 CSS px`):** Measured all non-inline interactive controls across all 21 routes at `320`, `390`, `1366`, `1536` px. Fixed `PageHeader` back links (`Semua pesanan`, `Semua produk`, `Kembali ke langganan`, `Semua landing page`) from `20px` height to `24px` (`min-h-6`).
6. **Confirm dialogs (`ConfirmSubmit`):** Verified destructive actions confirm with object-specific consequences before mutating (order reject/cancel, product image delete, member remove, channel revoke, feed token regenerate/revoke, marketing server token clear, buyer data redaction, LP unpublish).
7. **Console errors:** Zero JavaScript or CSP console errors across all routes and viewports.
