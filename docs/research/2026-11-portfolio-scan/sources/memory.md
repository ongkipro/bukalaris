# Tokophi / Mengantar / AutoLaris / Coolify project memory — findings for Bukalaris

## Source summary
- Owner's personal project memory, which is advisory and may be stale: `tokophi*`, `mengantar-*`, `autolaris-payment-integration`, `kiriminaja-*`, `99ribu-*`, `coolify-vps-dev`, `customer-messaging-pending`, `affiliate-portal-specs-project`, plus `~/.config/ai/memory/{ops-lessons,development,projects-sites}.md`.
- Tokophi is Bukalaris's direct predecessor: a Shopify-style Indonesian commerce SaaS with Next.js, Astro, Drizzle and PostgreSQL RLS. It went live on Coolify (Vultr Singapore) in July 2026 but was still blocked from a production release (Stage 4/7) as of the 2026-08 notes.
- Date range is 2026-07 to 2026-11-01. The notes say they are not re-certified, and several vendor and infrastructure claims have since been superseded.
- ADR-0006, TASKS and `docs/11` already encode many Tokophi lessons (`/submit` instead of `create_payment`, HMAC callbacks with verification by pull, `parseListPayment`, payUnpaid with 409 serialisation, backup with ACLs, Coolify migrate job). Most remaining value is in the process, ops and verification gaps.
- Not checked: I confirmed no code beyond reading memory, and I grepped Bukalaris docs only for coverage.

## Anti-patterns to avoid
- Labelling a runtime role `app` without a separate `APP_DATABASE_URL`, so prod silently runs as a superuser. (`tokophi-build-log.md:18`)
- Relying on a DB toggle as proof that a PSP channel works. (`tokophi.md:19`)
- A uniform API version prefix assumed for every vendor endpoint. (`kiriminaja-integration.md:19`)
- Trusting `drizzle-kit generate` output without reading the SQL. (`tokophi-deploy-workflow.md:17`)
- `pg_dump --no-owner --no-acl` for RLS databases. (`ops-lessons.md:55`)
- Using SQLSTATE 40001 for app-level optimistic-concurrency errors behind PostgREST, which triggers an unbounded retry loop (use 55000). Bukalaris does not use PostgREST today. (`ops-lessons.md:124-141`)
- Treating a 200, a small response or a healthy container as proof of a deploy. (`tokophi-deploy-workflow.md:30`)
- Running `npm install` in a hardlinked `node_modules` worktree, which corrupts every sibling. (`tokophi-deploy-workflow.md:28`)
- Querying a shared Coolify `application_deployment_queues` table unfiltered, which shows another app's builds. (`tokophi-deploy-workflow.md:25`)
- Flipping repo visibility from a stale note. The owner's instructions reversed within hours and the repo flipped six times. (`tokophi.md:10`; `tokophi-repo-private-ruling.md:11-15`)
- Lasting VPS plans written as fact (e.g. the planned ~$12 versus actual $48 per month) and surviving in notes. (`tokophi-market-and-hosting.md:21`)
