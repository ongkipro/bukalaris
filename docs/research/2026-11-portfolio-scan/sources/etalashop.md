# Etalashop (TokoΦ / tokophi) — findings for Bukalaris

## Source summary
- Etalashop (repo and product name: tokophi) is a multi-tenant Indonesian commerce SaaS: Next.js admin and Super Admin, an Astro storefront, Postgres with Drizzle and RLS, on one Vultr VPS running Coolify. Payments and shipping are platform-managed (AutoLaris and KiriminAja).
- Maturity: live since 2026-07-13. Snapshot dated 2026-10-11 with state VERIFIED, 116 migrations, 188 test files and 1,649 tests (`STATUS.md:33-51`).
- It has no real merchant revenue and no real parcel yet. Production still runs on the courier sandbox and then a production account with no couriers (`STATUS.md:47-51`, `BUILD-LOG.md:4176`).
- The value for Bukalaris is the incident log (`BUILD-LOG.md` ~4,300 lines, `CHANGELOG.md` ~4,700 lines) and the RELEASE and OBSERVABILITY lessons.
- Bukalaris M3 already absorbed the money model, callback and RLS patterns. This list covers the residue, mostly engineering-process guards and ops lessons.
- Source status, numbers and approvals are not Bukalaris facts. Vendor facts need re-verification.
- I did not read all of the two big logs; I scanned headings and opened about 40 entries, so a few incidents may be missing.

## Anti-patterns to avoid
- Gating a check through a pipe (`… | tail -3`): the exit code belongs to `tail`, and errors were cut off (`BUILD-LOG.md:204`).
- Listing the guarded files by name instead of deriving the class. A guard on `checkout.astro` by name missed the second form (`BUILD-LOG.md:1152`).
- Declaring a cause without measuring the fixed state; the first "cause" didn't fix the booking (`BUILD-LOG.md:1275`).
- Checking only `docker compose config`; Coolify has its own parser (`BUILD-LOG.md:129`).
- A read-then-write uniqueness or one-per-session check (`BUILD-LOG.md:1194`, `CHANGELOG.md:157`).
- Flooring stock with `GREATEST(…,0)`: it destroys evidence (`CHANGELOG.md:1823`).
- A fail-open secret check in dev that hides a prod 401 (`CHANGELOG.md:1804`).
- Cache keys without environment or credential (`BUILD-LOG.md:4176`).
- Caching an empty vendor answer.
- Writing a sample of a forbidden config form inside a comment (`BUILD-LOG.md:129`).
- Alarms with no named recipient (`specs/docs/tasks/2026-08-06-alerting-gaps.md:1`).
- Repo visibility flipped seven times to manage CI minutes, so public history stays indexed. Bukalaris should prefer paid CI over flipping (`DECISIONS.md:43`, DEC-009).
- Parallel lanes sharing one checkout, with a `server-only` import leaking into a package the storefront bundles (`BUILD-LOG.md:30`).
- Doc/status "VERIFIED" that rests on the sandbox vendor endpoint (`STATUS.md:47-51`).

## Not applicable to Bukalaris
- KiriminAja specifics (kelurahan ids, coordinates as centroids, sorting code, force_insurance, UAT sheets): Bukalaris uses Mengantar. Treat them as patterns only.
- Provider-brand hiding ("TokoΦ Kirim/Bayar", ADR 0004): Bukalaris owns the Mengantar and AutoLaris brand decisions in its own ADRs.
- Astro storefront, Puck theme builder, per-tenant theme tokens, mega menu and srcset work: Bukalaris is Next.js, and its builder boundary is ADR-0003.
- PPN toggle default OFF and subscription prices (DPP): Bukalaris has its own tax ADR-0012 and plan decisions.
- Repository-hygiene items (41 agent worktrees, AI-trailer history, GitHub minutes): Bukalaris `AGENTS.md` already forbids AI trailers.
- Single-VPS capacity, disk and swap numbers, Vultr billing, and the Coolify version upgrades: device and infra specifics to re-measure.
- Etalashop's tenant-theme visual, mockup and UX polish entries (card ratios, palette): design taste belongs to Bukalaris' own design system doc.
