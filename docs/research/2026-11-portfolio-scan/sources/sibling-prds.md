# sibling-prds (99ribu, GeraiExpress, geraicuan) — findings for Bukalaris

## Source summary
- 99ribu (one fixed-price retailer) and GeraiExpress (Mengantar shipping SaaS) are PRD/spec packs. They are staged specs with "runtime pending", not shipped products.
- The notes are a legacy-comparison of **geraicuan** (a Next.js, Better Auth and Postgres app by the same owner) and a 99ribu admin redesign plan (2026-10-29). Both are static reads, not executed. geraicuan's `origin/main` has been live on a Vultr/Coolify VPS since 2026-10-10, with live ordering still off. The pg-migration inventory is Supabase-specific.
- Date range is 2026-09 to 2026-10-29.
- Bukalaris has already absorbed much of the 99ribu pack (`docs/DECISIONS.md:348`, `docs/TASKS.md:555`), so most 99ribu items are marked partly covered.
- Path aliases: **INV** = `notes/geraiexpress-legacy-comparison/lane-INV.md`, **ARCH** = `…/lane-ARCH.md`, **REV** = `notes/99ribu-admin-dashboard-review-20261029.md`, **GBILL** = `prd/geraiexpress/11-BILLING-PAYMENTS.md`. Coverage was checked with `rg` only.

## Anti-patterns to avoid
- Hard-coding provider fee percentages in DB CHECKs: `notes/geraiexpress-legacy-comparison/lane-ARCH.md:135-146`.
- Holding an advisory lock across an external call on a shared pool: `lane-ARCH.md:119-134`.
- Marking a task done when the route is closed or no writer exists: `lane-INV.md:117-138`.
- Dev-only audit branches driven by a request header inside production code (18 files, a 734-line registry): `lane-INV.md:182-185`.
- Sanctioned fixture modules living in production code: `lane-INV.md:182-185`.
- Four near-identical fixed-window rate-limiter modules instead of one: `lane-INV.md:186`.
- Docs that describe a later tree than the code, such as `18-SYSTEM-MAP.md` with a stale `file://` link: `lane-INV.md:127,221-232`.
- Recovery that happens only when an admin visits a page: `lane-ARCH.md:163-174`.
- Removing the finance and reconciliation UI while the reconcile function stays with no caller: `lane-ARCH.md:151-162`.
- A single secret reused across sessions, TOTP and HMAC keys: `lane-ARCH.md:59-93`.
- Copying a SaaS tenant feature into a fixed-price brand app (emoji greeting, Flash Sale vouchers): `notes/99ribu-admin-dashboard-review-20261029.md:142-148`.

## Not applicable to Bukalaris
- `notes/geraiexpress-pg-migration/*`: Supabase `auth.*` dependency inventory. Bukalaris is already on plain Postgres, Drizzle and Better Auth.
- `notes/mengantar-design-system.md` and `notes/99ribu-design-system.md`: Mengantar's brand and type scale. Bukalaris has its own design system (`docs/10`).
- 99ribu's fixed Rp 99,000 offers, HPP margin floor, warehouse-component stock and "Berlapak" origin warehouses: single-company retail, not multi-tenant COD sellers.
- GeraiExpress's Supabase/Cloudflare Workers stack decisions (JWT-bound RLS, Workers cron): Bukalaris chose Next.js and Postgres RLS (ADR-0005, ADR-0008).
- Dark mode and a store switcher in the tokophi admin: the 99ribu plan rejected them, and Bukalaris decides separately.
- Indonesian law and tax statements in the source packs: all are marked unknown or pending there, so re-verify them from official sources before use.
